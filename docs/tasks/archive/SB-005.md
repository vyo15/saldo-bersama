## Objective

Mencegah task yang sudah DONE/archived menyisakan Acceptance Criteria belum dicentang, Remaining/Resume From yang masih aktif, atau validation evidence lama yang mengatakan NOT RUN setelah `task:finish` sebenarnya sudah sukses.

## Acceptance Criteria

- [x] `task:finish` menormalisasi metadata closure sebelum task dipindah ke archive.
- [x] Acceptance Criteria task yang berhasil ditutup menjadi checked.
- [x] `Remaining` dan `Resume From` otomatis menjadi state selesai.
- [x] `Validation Actually Run` mencatat canonical gate yang benar-benar dijalankan helper.
- [x] Browser evidence hanya dicatat PASS bila browser validation memang diwajibkan affected path.
- [x] Validator menolak archived task yang masih memiliki unchecked acceptance, active remaining/resume, atau validation NOT RUN.
- [x] Archive SB-003 dan SB-004 direkonsiliasi agar konsisten dengan status DONE aktual.
- [x] Regression test membuktikan auto-closure bekerja end-to-end dan tidak bergantung pada edit manual setelah merge.
- [x] Workflow docs/template menjelaskan closure otomatis agar agent berikutnya tidak menghidupkan pola lama.

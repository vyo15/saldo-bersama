## Objective

Mengganti global handoff workflow dengan task-driven multi-team workflow yang dapat dilanjutkan lintas chat/perangkat, memiliki ownership yang mudah dibaca, dependency queue, checkpoint, scope guard, dan validator otomatis tanpa mengubah runtime finansial aplikasi.

## Acceptance Criteria

- [x] Nama team canonical hanya `COORD`, `UIUX`, `FE`, `BE`, `DB`, `QA`.
- [x] Status canonical hanya `DRAFT`, `READY`, `APPROVED`, `IN_PROGRESS`, `ON_HOLD`, `READY_FOR_QA`, `READY_FOR_MERGE`, `DONE`.
- [x] Agent wajib mengidentifikasi team pada awal respons substantif task.
- [x] `PROJECT_HANDOFF.md` global dan `TEAM_OWNERSHIP.md` lama tidak lagi menjadi workflow aktif.
- [x] Satu task card per pekerjaan menjadi handoff/checkpoint canonical.
- [x] Dependency, WIP limit, parent/work package, interrupt, freshness, batch same-scope, QA, dan integration flow terdokumentasi.
- [x] `npm run task:list` dapat menunjukkan antrean dan recommended next dari task card.
- [x] `npm run task:check` menolak task/branch/scope/dependency/guarded mismatch.
- [x] CI/full quality gate menjalankan task governance check.
- [x] Referensi governance lama dibersihkan tanpa menyentuh business logic, schema, auth, saldo, backup, atau deployment runtime.

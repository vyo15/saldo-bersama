## Objective

Menutup seluruh temuan maintainability yang masih tervalidasi setelah SB-003 dalam satu paket terkoordinasi: menyelaraskan guarded-path policy, membuat VAPID validation dan test fixture canonical/deterministik, menambah characterization test pada alur backend/data-integrity berisiko tinggi, menghapus duplikasi serialization backend dan browser harness, serta membersihkan facade/presentation compatibility frontend yang sudah tidak diperlukan.

## Acceptance Criteria

- [ ] Backend/data runtime, Apps Script, database, repository workflow, environment/deployment tooling, dan governance global fail-closed sebagai guarded path.
- [ ] CODEOWNERS dan task validator tidak drift untuk boundary high-risk utama.
- [ ] VAPID runtime/backend memakai satu pure validation implementation canonical.
- [ ] Test VAPID selalu menghasilkan private scalar tepat 32 byte.
- [ ] High-risk characterization mencakup users, goals, envelopes, recurring, period reopen, backup, import, dan restore failure/replay paths.
- [ ] Backend `stableValue`/canonical JSON hanya memiliki satu implementation server-side.
- [ ] Browser smoke memakai canonical browser runtime helper dan tidak menduplikasi server/Chromium/CDP lifecycle.
- [ ] Accounts facade tidak lagi memiliki reconciliation API residual.
- [ ] Presentation compatibility wrappers yang tidak lagi dipakai sudah dipensiunkan.
- [ ] `task:finish` menjalankan browser validation berdasarkan affected path, termasuk task integrasi COORD yang menyentuh frontend/browser.
- [ ] Relevant regression tests dan source validation PASS; full canonical gate dijalankan oleh `task:finish` di Node 24 sebelum merge.

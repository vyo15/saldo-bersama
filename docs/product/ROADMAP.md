# Roadmap

Roadmap menunjukkan urutan, bukan janji tanggal. Status canonical fitur tetap berada di `IMPLEMENTATION_MATRIX.md`.

## Now

- Governance dan handoff antar-agent.
- Migration parity Turso.
- Real-resource backup/restore drill.
- GitHub branch protection dan release gate.

## Next

- Observability coverage, metrics, client error reporting, dan alert.
- Playwright E2E serta axe accessibility.
- Performance budget dan smoke test deployment.
- Security/dependency automation sesuai fitur GitHub yang tersedia.

## Later

- Evaluasi ulang guard operasional database tunggal melalui RFC bila jumlah pengguna atau tim bertambah.
- Enkripsi backup aplikasi dengan key lifecycle yang disetujui.
- Contract schema machine-readable per action.
- Disaster-recovery drill berkala dan SLO.

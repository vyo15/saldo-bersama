# Definition of Ready

Task siap dikerjakan bila:

- masalah dan outcome jelas;
- acceptance criteria dapat diuji;
- scope dan non-goal ditulis;
- source terbaru tersedia dan area terdampak sudah dipetakan;
- owner/reviewer ditentukan;
- dampak API, schema, auth, saldo, audit, backup, security, UI, dan deployment dinilai;
- kebutuhan RFC/ADR diputuskan;
- data test memakai dummy;
- test plan dan rollback/forward-fix awal tersedia;
- dependency/secret baru sudah mendapat approval.

Task guarded tidak boleh dimulai hanya dari instruksi singkat tanpa source review dan approval plan.
